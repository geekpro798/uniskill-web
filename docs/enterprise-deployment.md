# UniSkill 企业私有化部署方案

## 概述

UniSkill 采用 **Gateway 与 Skill 分离架构**。技能（Skill）本质是描述 API 调用方式的 YAML/Markdown 配置文件，真正的执行层是 MCP Gateway——它解析技能定义、鉴权、路由请求、计费。

因此私有化部署的核心问题是 **Gateway 放在哪里**，而非技能文件放在哪里。

我们提供三种部署模式，覆盖从轻量接入到完全私有化的全场景。

---

## 模式一：Gateway 托管 + API 专线（共享网关）

### 架构

```
┌─────────────────────────────────────────────────┐
│                  UniSkill Cloud                   │
│  ┌───────────────────────────────────────────┐  │
│  │           MCP Gateway (多租户)              │  │
│  │  · 鉴权 (Session Key / EIP-191)            │  │
│  │  · 路由 → Private Registry                 │  │
│  │  · 计费                                    │  │
│  └───────────────────────────────────────────┘  │
│                       │                          │
└───────────────────────┼──────────────────────────┘
                        │ Cloudflare Tunnel / 专线
                        │
┌───────────────────────┼──────────────────────────┐
│              企业内网 / VPC                        │
│                       │                          │
│  ┌──────────┐  ┌──────┴─────┐  ┌─────────────┐  │
│  │ 内部 API │  │ 内部 API   │  │ 内部 API    │  │
│  │ (Jira)   │  │ (数据库)   │  │ (自研服务)  │  │
│  └──────────┘  └────────────┘  └─────────────┘  │
└──────────────────────────────────────────────────┘
```

### 工作流

1. 企业在 UniSkill 创建 **Private Registry**（私有技能注册表）
2. 将内部 API 封装为技能，注册到私有表中
3. 通过 Cloudflare Tunnel 或 VPN 专线，将内网 API 安全暴露给 UniSkill Gateway
4. 团队成员用 Session Key 连接 Gateway → Agent 调用企业技能
5. 管理员可在 Dashboard 查看全量审计日志

### 特点

| 维度 | 说明 |
|------|------|
| 部署方式 | 无需部署，开通 Tunnel 即可 |
| 数据路径 | API 请求经 Gateway 转发，响应数据经过 UniSkill 基础设施 |
| 运维成本 | 零运维 |
| 隔离性 | 技能定义隔离，数据链路共享 |
| 适合客户 | 中小团队、非强合规场景 |

## 模式二：Gateway 部署至企业 Cloudflare 账号（专属网关）

### 架构

```
┌──────────────────────────────────────────────────┐
│            企业 Cloudflare 账号                     │
│                                                   │
│  ┌────────────────────────────────────────────┐  │
│  │        Gateway Worker (专属实例)             │  │
│  │  · 企业独占 KV Storage                      │  │
│  │  · 企业独占 Durable Objects (会话状态)       │  │
│  │  · 直连企业内网 API                          │  │
│  └────────────────────────────────────────────┘  │
│                       │                           │
│            ┌──────────┼──────────┐               │
│            ▼          ▼          ▼               │
│      ┌────────┐ ┌────────┐ ┌────────┐           │
│      │ 内部API│ │ 内部API│ │ 内部API│           │
│      └────────┘ └────────┘ └────────┘           │
└──────────────────────────────────────────────────┘
```

### 工作流

1. UniSkill 提供 Gateway Worker 部署包（含配置脚本）
2. 企业执行一键部署脚本 → Gateway 运行在自己 Cloudflare 账号下
3. 技能定义、会话状态、调用日志全部存储在企业 KV/DO 中
4. 企业 Agent 直连专属 Gateway，数据不经过 UniSkill

### 特点

| 维度 | 说明 |
|------|------|
| 部署方式 | 一键脚本部署到企业 Cloudflare 账号 |
| 数据路径 | 数据完全在企业 Cloudflare 账号内，不经 UniSkill |
| 运维成本 | 低（Cloudflare 托管，无需管服务器） |
| 隔离性 | 计算 + 存储 + 网络完全隔离 |
| 适合客户 | 中型企业、有数据合规要求、已有 Cloudflare 账号 |

## 模式三：完全私有化部署（自建 Gateway）

### 架构

```
┌──────────────────────────────────────────────────┐
│              企业机房 / VPC / K8s                   │
│                                                   │
│  ┌────────────────────────────────────────────┐  │
│  │        UniSkill Gateway (Docker)            │  │
│  │  · 替代 KV → Redis                         │  │
│  │  · 替代 DO  → PostgreSQL                    │  │
│  │  · MCP SSE / JSON-RPC 端点                  │  │
│  └────────────────────────────────────────────┘  │
│                       │                           │
│            ┌──────────┼──────────┐               │
│            ▼          ▼          ▼               │
│      ┌────────┐ ┌────────┐ ┌────────┐           │
│      │ 内部API│ │ 内部API│ │ 内部API│           │
│      └────────┘ └────────┘ └────────┘           │
│                                                   │
│  可离线运行 · 无需外网 · 完全自主                    │
└──────────────────────────────────────────────────┘
```

### 工作流

1. UniSkill 提供 Gateway Docker 镜像 + 部署文档
2. 企业部署到自有 K8s / Docker Compose / 裸机
3. 对接企业自有 Redis + PostgreSQL
4. 完全离线运行，无需 UniSkill 云端任何服务

### 特点

| 维度 | 说明 |
|------|------|
| 部署方式 | Docker 镜像，部署到企业自有基础设施 |
| 数据路径 | 数据完全不出企业网络 |
| 运维成本 | 高（需自管服务器、数据库、高可用） |
| 隔离性 | 物理/网络完全隔离 |
| 适合客户 | 金融、政务、军工等强合规场景 |

## 常见问题

**Q: 企业技能调用的 API 需要改造吗？**

不需要。技能只是描述已有 API 的调用方式（Method、URL、Headers、Body），企业 API 无需任何改造。

**Q: 员工离职后怎么处理？**

在 UniSkill Dashboard 一键 Revoke 该员工的 Session Key，即刻切断访问。企业版支持 SSO 集成，离职自动撤销。

**Q: 模式二的升级和补丁怎么处理？**

Gateway Worker 由 UniSkill 维护，通过 CLI 命令一键更新到最新版本。Worker 本身无状态，更新不影响运行中的请求。

**Q: 技能市场 (Market) 的社区技能能在私有化部署中使用吗？**

模式一可以。模式二/三默认不连接公共 Market，但企业可按需选择性同步特定社区技能。
